# ربات فضای شخصی فایل تلگرام 📁

یک ربات Cloudflare Workers برای فهرست‌کردن عکس، ویدیو و سندهای ارسالی هر کاربر در گفتگوی خصوصی. رسانه با `file_id` تلگرام بازیابی می‌شود؛ خود فایل در Cloudflare آپلود نمی‌شود و فقط شناسه، نام و توضیح آن در Durable Object ذخیره می‌شود. بازی قبلی جایگزین شده است.

## استفاده

1. به ربات در **گفتگوی خصوصی** `/start` بفرستید.
2. عکس، ویدیو یا سند ارسال کنید. برای ذخیره بدون فشرده‌سازی تلگرام، عکس یا ویدیو را به‌صورت **فایل/سند** بفرستید.
3. با `/drive` پنجره گرافیکی تلگرام را باز کنید و فایل‌ها را ببینید، دریافت کنید یا از فهرست حذف کنید. دریافت، فایل را به گفتگوی خصوصی ربات ارسال می‌کند. همچنین `/files` فهرست متنی داخل چت را باز می‌کند. فهرست صفحه‌بندی شده است.

حذف، فقط مورد را از فهرست ربات برمی‌دارد؛ پیام‌های ارسالی قبلی را از تلگرام حذف نمی‌کند. این ربات فایل‌ها را در گروه ذخیره یا نمایش نمی‌دهد. فایل‌ها و فراداده‌ها تابع سیاست و محدودیت‌های تلگرام و Cloudflare هستند، محرمانگی کامل یا ماندگاری دائمی تضمین نمی‌شود و مدیر ربات/زیرساخت ممکن است به داده‌ها دسترسی داشته باشد. **برای فایل‌های مهم یا محرمانه نسخه پشتیبان مستقل و امن داشته باشید.** حذف ربات، تغییر توکن/ربات، حذف داده‌های Durable Object یا تغییر سیاست تلگرام ممکن است بازیابی را غیرممکن کند. محدودیت اندازه و نوع فایل را تلگرام تعیین می‌کند.

## راه‌اندازی Cloudflare Workers

مخزن را به یک **Worker** (نه Pages) متصل کنید، شاخه `main` را انتخاب کنید، Build command را `npm install` و Deploy command را `npx wrangler deploy` قرار دهید. Durable Objects باید در حساب شما در دسترس باشد.

در **Settings → Variables and Secrets** دو Secret بسازید:

- `BOT_TOKEN`: توکن ربات از BotFather.
- `TELEGRAM_SECRET`: یک رشته تصادفی محرمانه با ۱ تا ۲۵۶ کاراکتر؛ فقط حروف انگلیسی، عدد، `_` یا `-`.

پس از Deploy، صفحه اصلی آدرس Worker را باز کنید، `TELEGRAM_SECRET` را وارد و دکمه فعال‌سازی را بزنید. اگر توکن، secret یا آدرس Worker تغییر کرد، دوباره فعال‌سازی کنید. مقدارها را در مخزن قرار ندهید. فایل پیکربندی Durable Object موجود را حفظ می‌کند تا به استقرار فعلی متصل شود؛ داده‌های قدیمی بازی به‌طور خودکار پاک نمی‌شوند.

پنجره گرافیکی باید از دکمه ربات در تلگرام باز شود؛ برای حفاظت از فایل‌ها، هویت کاربر از داده امضاشده تلگرام در سرور بررسی می‌شود.
